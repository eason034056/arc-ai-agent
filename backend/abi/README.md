# Smart Contract ABI

This directory stores the ABI (Application Binary Interface) files for smart contracts.

## Files

- `PayrollVault.json` - PayrollVault contract ABI
- `PayrollVault.address` - Deployed contract address

## Generation Method

These files are automatically generated by the deployment script in the `contracts/` directory:

```bash
cd contracts
npx hardhat run scripts/deploy.ts --network arcTestnet
```

The deployment script automatically copies the ABI to this directory.
